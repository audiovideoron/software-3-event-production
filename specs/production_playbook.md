# Production Playbook

House rules for laying out a room. These apply to every render and are venue-agnostic and event-agnostic. Add to this file as new rules surface; when something here conflicts with a venue or event spec, the more specific spec wins.

## Stated Rules (so far)

1. **All chairs face the focal point** — every attendee chair faces the stage and screens. A chair facing away from the screens is never acceptable.
2. **Minimum 8 ft (target 10–12 ft) between any screen face and the first row of tables/chairs.**
3. **Seating fills the available room** — when laying out chairs and tables in a defined active area, distribute them across the full usable width and use as much depth as needed. Do not leave large unoccupied gaps on the sides.
4. **Render only what is documented** — the spec files (venue + inventory + event + this playbook) are the source of truth. Do not add standard-practice elements (ADA seating, default lecterns, pipe and drape, etc.) unless they appear in one of the specs.
5. **Projection screen position is determined by audience sightlines, not stage geometry.** With N screens dividing the audience into N column-blocks, each screen sits on the aisle that bisects its assigned block. Screens move off the stage area to those aisle positions. Example: with 4 seating columns and 2 screens, screen L centers on the aisle between cols 1 and 2; screen R centers on the aisle between cols 3 and 4.

## Notes

- Furniture specs (table dimensions, chair count) live in `inventory.md`.
- Playbook entries should explain *the rule*, not the example that motivated it.
